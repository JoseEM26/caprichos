# Caprichos

Plataforma digital de Caprichos, café artesanal en Lima: carta virtual, administrativo (pedidos, caja, cocina, reparto, stock), chatbot de WhatsApp y modo sin internet.

| Carpeta | Qué hay |
|---|---|
| [`docs/`](docs/README.md) | Toda la documentación: análisis, épicas, features, historias, ADR, datos, operación y plan de pruebas |
| `mockup/` | Fuente del mockup navegable del administrativo y la carta |
| `legacy/` | Proyecto anterior (bot, web y mockup viejos), solo de consulta |
| `.claude/` | Skills del equipo (marco Aybar) |

Los datos de clientes, las claves y los archivos con sesiones no se suben (ver `.gitignore`). El código de la plataforma vive en `apps/`, `packages/` e `infra/` y llega con la ola 0.
