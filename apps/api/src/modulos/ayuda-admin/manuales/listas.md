# Listas y categorías

## Para que sirve
Permite organizar la carta del negocio en secciones claras y administrar los listados de opciones personalizables que los clientes eligen al pedir, tales como tamanos, sabores, salsas, tipos de endulzante o adicionales. Cada apartado conserva su propia lista independiente para mantener ordenados los combos y articulos en [[productos]].

## Como se hace: Crear una nueva categoria de opciones
1. En la columna izquierda de la pantalla, pulsa el boton "+ Nueva categoria".
2. En el campo "Nombre de la categoria de opciones", escribe el nombre descriptivo (por ejemplo: Salsas, Toppings, Tipos de pan).
3. Pulsa el boton "Crear categoria". La lista se anadira de inmediato al menu lateral izquierdo.
Despues: [[productos]]
Ver tambien: [[disenador]]

## Como se hace: Agregar elementos a una lista
1. En la columna izquierda, pulsa sobre la lista u opcion en la que deseas trabajar para seleccionarla.
2. En el panel principal de la derecha, escribe el nombre del nuevo valor en el campo "Nuevo elemento".
3. Pulsa el boton "+ Agregar". El nuevo elemento aparecera en la parte inferior de la tabla.
Despues: [[productos]]
Ver tambien: [[recetas]]

## Como se hace: Modificar o reordenar elementos
1. Selecciona la lista correspondiente en el panel izquierdo.
2. Para cambiar la posicion de un elemento en la carta, utiliza los botones con flechas hacia arriba o hacia abajo en la fila correspondiente.
3. Para corregir el nombre de un elemento, pulsa el boton "Editar", escribe la modificacion en el campo de texto y pulsa "Guardar".
Ver tambien: [[disenador]]

## Como se hace: Ocultar o reactivar un elemento de una lista
1. Ubica el elemento en la tabla del panel derecho.
2. Pulsa el boton "Ocultar" (o "Reactivar" si estaba previamente inactivo).
3. Aparecera un cuadro de confirmacion explicando que el elemento dejara de ofrecerse en la carta virtual y en las opciones de pedido.
4. Pulsa "Si, continuar". El elemento quedara marcado como inactivo sin perder su historial en comandas previas.
Ver tambien: [[productos]]

## Errores y dudas comunes
- No puedo borrar una opcion por completo: las opciones y categorias no se eliminan para no alterar pedidos historicos ni comprobantes registrados; la forma correcta de retirarlas es usando la accion de ocultar.
- Diferencia entre categorias de la carta y listas de opciones: las categorias de la carta agrupan productos principales para la venta (como Frappes o Waffles), mientras que las listas de opciones definen variantes y agregados dentro de cada producto (como Grande o Sin azucar).
- Los cambios no se ven en la carta: tras ocultar o renombrar un elemento, la carta virtual actualiza las opciones en cuanto el cliente abre el producto.

## Quien puede hacerlo
- Administrador: tiene control completo para crear categorias, agregar elementos a las listas, modificar nombres, ajustar el orden y ocultar o reactivar elementos.
- Cajero: puede entrar al modulo para revisar que categorias y opciones se encuentran configuradas en el sistema, pero no puede crear ni editar elementos.
- Otros roles (Cocina, Mozo, Repartidor, Almacen): no tienen acceso a este modulo.
