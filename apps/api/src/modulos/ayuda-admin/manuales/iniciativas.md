# Iniciativas

## Para que sirve
Espacio colaborativo para que el personal de diferentes areas registre quejas operativas, propuestas de mejora o ideas con fotos de respaldo. Permite al equipo debatir en comentarios y al administrador gestionar el estado de cada iniciativa, quedando registrado en el [[historial]] de auditoria.

## Como se hace: Registrar una nueva iniciativa
1. En la parte superior de la pantalla, pulsar el boton + Nueva iniciativa.
2. En el formulario, seleccionar el Tipo entre Queja, Mejora o Idea.
3. Elegir el Area afectada: Carta web y pedidos en linea, Pedidos y caja, Cocina y barra, Reparto y delivery, Almacen y compras u Otro.
4. Escribir un Titulo corto y explicar en Detalle que sucede o que se propone.
5. Opcionalmente, pulsar Seleccionar foto o arrastrar una imagen (maximo 5 MB) para adjuntar evidencia visual.
6. Pulsar el boton Subir iniciativa. Aparecera la ventana de confirmacion con la pregunta: ¿Subir iniciativa al equipo?.
7. Confirmar pulsando el boton Si, subir. La iniciativa quedara registrada con tu usuario y la vera todo el personal.
Ver tambien: [[historial]]

## Como se hace: Comentar una iniciativa
1. Buscar la iniciativa en la lista o usar los filtros superiores (Todos, Quejas, Mejoras, Ideas, o por estado).
2. Pulsar el boton Ver y comentar en la tarjeta de la iniciativa para desplegar el detalle.
3. Escribir el comentario en el campo Escribe un comentario para el equipo.
4. Pulsar el boton Enviar comentario.
Ver tambien: [[usuarios]]

## Como se hace: Cambiar el estado de una iniciativa (Solo Administrador)
1. Abrir la iniciativa pulsando Ver y comentar.
2. En la seccion de estados de la tarjeta, pulsar el boton del estado deseado: Pasar a En revision, Marcar como Hecha o No por ahora.
3. Aparecera la ventana de confirmacion: ¿Cambiar estado a "...?.
4. Pulsar el boton Si, cambiar. El cambio quedara registrado en el [[historial]] de auditoria del sistema.
Despues: [[historial]]

## Errores y dudas comunes
- Si la imagen seleccionada supera los 5 MB, el sistema muestra el error: La captura no puede superar los 5 MB. Debe comprimir la foto antes de subirla.
- Las iniciativas no se pueden eliminar para mantener la transparencia del equipo; si una propuesta no procede, el Administrador la marca como No por ahora con su respectiva justificacion.
- Si no se completan el titulo o el detalle, el sistema no permite continuar y resalta los campos pendientes.

## Quien puede hacerlo
- Pueden ver, crear iniciativas y comentar: Administrador, Cocina, Mozo, Call Center, Almacen y Repartidor.
- Unicamente el Administrador puede cambiar el estado de las iniciativas.
- El rol Cajero no tiene acceso a este modulo segun la matriz de permisos.
