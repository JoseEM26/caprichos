# Web administrativa del cliente (restaurant.pe)

Sistema POS/administrativo en producción: `https://caprichos.restaurant.pe/restaurant/`. Se analizó en **solo lectura** con una cuenta de consulta. No se creó, editó ni eliminó nada, ni se cobró ni abrió caja.

| Archivo / carpeta | Contenido |
| :-- | :-- |
| `consolidado-reunion.md` | Imprescindibles, mejoras y dudas de los 15 informes, juntos, para preparar la reunión con el cliente |
| `modulos-lista.md` | Los 17 módulos funcionales y lo excluido (publicidad de la plataforma) |
| `modulos.md` | Mapa del menú con rutas y tecnología observada |
| `modulos-usuarios-notificaciones.md` | Notificaciones, perfil y usuarios (roles, permisos, formulario) |
| `modulos/<módulo>.md` | Informe detallado de cada módulo (15 informes): escritorio, ventas, productos, delivery, caja, reservas, clientes, promos, creditos, compras, almacen, informes, mirest, ajustes-a, ajustes-b |
| `modulos/<módulo>/` | Archivos de trabajo de cada agente (scripts, código descargado de la app); ocupan unos 80 MB y no hace falta compartirlos |
| `plan-olas.md` | Cómo se repartió el análisis |

Aviso: los informes se apoyan en parte en la lectura del código de la aplicación, no solo en lo que se ve en pantalla. Las carpetas de trabajo pueden traer claves públicas de Google Maps y datos de estructura del sistema; revisar antes de compartir.
