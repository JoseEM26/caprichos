Requisitos para impresion

Para poder imprimir debe tener en cuenta los siguiente
  1. Debe tener instalado el siguiente servicio: desde este enlace
  2. Instalar Setup1.msi
  3. El archivo modelo.repx debe ser pegado dentro de C:\Program Files (x86)\RESTAURANT.PE SAC\Printer
  4. La impresora en la que se imprimira debe tener el nombre de "GUIAS"
