# Web anterior de Caprichos

Información extraída de las webs anteriores del cliente. Cada web va en su propia carpeta, sin mezclar datos.

| Carpeta | Qué es | Estado |
| :-- | :-- | :-- |
| `carta/` | Web de pedidos anterior (OlaClick, `caprichos-per.ola.click`): catálogo, imágenes, flujo de carrito y checkout, enlaces y código | Extraída |
| `administrativo/` | Web del módulo administrativo | Pendiente (llegará después) |

La carta vigente es la de los PDF en `../recursos/` (ver `../recursos/carta-completa.md`). Lo de `carta/` es una fuente histórica y sus precios pueden estar desactualizados.
